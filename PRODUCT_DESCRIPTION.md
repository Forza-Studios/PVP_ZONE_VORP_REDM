# 🔥 COI Zone Top Kills - The Ultimate PvP Leaderboard

Dominate your RedM server's PvP zones with this premium, high-performance leaderboard script. Designed for stability, aesthetics, and FULL customization.

## 🌟 Why Choose This?
Unlike generic scripts, **COI Zone Top Kills** is built for performance and user experience. It uses **SQL** for robust data saving and includes unique visual effects for kill streaks. Plus, it's **Open Source**, so you can change everything including colors and fonts!

## 🚀 Key Features

### 📊 Dynamic Leaderboard
- Displays the **Top 3 Killers** in real-time.
- Shows **"YOUR TOTAL KILLS"** in a dedicated footer row, so every player knows their standing instantly.
- Smooth animations and a premium dark/cyan/gold theme.

### 🎨 Fully Customizable Design
- Don't like Cyan? Want Red, Green, or Purple?
- Easily edit `style.css` to change all colors, fonts, and borders to match your server's unique brand.
- **Open Source:** No encrypted files. You own the code.

### ⚔️ Kill Feed & Streaks
- **Kill Feed:** Notifications for every kill inside the zone.
- **Streak 5:** Player name glows **GOLD**.
- **Streak 10:** Player name pulses with **LIGHTNING & FIRE** effects (⚡).
- **Streak Breaker:** Losing a streak of 3+ triggers a "Streak Lost" notification to the victim.

### 💾 Robust SQL Saving
- Uses `oxmysql` to save every kill, streak, and name directly to the database.
- **No JSON files**, no data corruption, no resets on restart!

### 🛡️ Optimized & Crash-Free
- **Smart Loop:** The script "sleeps" when players are far from the zone (0.00ms usage).
- **Offline Capable:** Includes local libraries, so the UI **never** disappears due to lag or internet issues.
